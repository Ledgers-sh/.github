# Ledgers-sh/.github

The organization profile for [Ledgers-sh](https://github.com/Ledgers-sh): `profile/README.md`
is what GitHub shows on the organization page. `assets/` holds the banner, the animated mark
and the avatar, all rendered from the website repository (`tools/render-og.sh`).
The avatar is uploaded by hand at `github.com/organizations/Ledgers-sh/settings/profile`.
